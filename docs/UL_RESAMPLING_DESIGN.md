# ULのデータ再標本化による安定性（設計時のメモ）

既存repeat-ulは同じ全データで初期化seedを変えます。次の段階では、データの一部を取り除いたときにクラスタ構造が保たれるかを別の入口で測ります。DL反復と同様、既存の挙動を変更せず独立した機能として追加します。

最初は重複行の対応が不要な「非復元の部分抽出」を候補とします。bootstrapとは呼びません。抽出seedとモデルの初期化seedを分離し、参照データ・抽出index・設定・割当・状態を全反復で保存します。初期化seedを固定しても、データを変えれば初期中心の選ばれ方が変わるため、初期値そのものを固定した実験とは区別します。

前処理を含む手順全体の安定性を測る場合、各部分集合だけでscalerをfitします。全データのscalerを共有する実験とは測定対象が異なるので、暗黙には混ぜません。全データ参照モデルとの比較は、その部分集合の元行indexだけに限定したAssignment ARIとします。反復間の比較は共通行の集合に限定し、共通行数を必ず記録します。

Target ARIはラベルとの診断として別列に保存します。Target ARIやtest値で候補を選びません。共通行が少なすぎる比較や単一クラスタへ崩れた場合は、数値が計算できることだけで安定と解釈せず、状態と観測クラスタ数を示します。依存する反復対を独立標本としたSEM/CIも作りません。

実装前に、対象手法・kの範囲、抽出割合・反復数、標準化方針、計算量上限と失敗状態の仕様をコードとテストへ落とし込みます。Silhouetteの全件計算を大量反復へそのまま持ち込まず、組込みデータで負荷を測ります。現在のサポートはラベル付き数値CSVであり、ラベルなしUL対応は別の機能です。

完了条件は、同一抽出seedのindex再現、indexと割当の対応、共通行限定のARI、部分集合内だけのscaler fit、失敗時の保存、独立wheel環境での照合です。この文書は設計の背景を示す記録です。実装範囲と検証結果は操作ガイドと検証資料を参照してください。
