## 実測と判断

- **DIYの標準データ検証**。Wine・Seeds・Breast Cancer Wisconsinで `select` と `tune` を同じ分割で実行し、合計480 foldの途中経過と18点のレポートを照合した。この分割では `tune` のCV平均は3データで上昇し、保留の正解数はSeedsで1件増、WineとBreast Cancer Wisconsinで各1件減った。集計、図、進捗ログを実験ディレクトリに残した。 [標準分類の実験レポート](../experiments/sl_report_validation/README.md)
- **軽量分類の外部照合**。Iris・Wine・Seedsの共通保留行で、DIYと各外部ライブラリの予測が異なる行はベンチマークごとに0〜2件だった。SeedsはDIYとAutoGluonが42件全て一致し、保留macro F1はともに0.8731。H2Oは0.9277で2件多く正解し、その差の条件付き95%区間はゼロを含んだ。各手法の学習記録は候補やfoldの単位が異なるため、設定を参照しながら保留予測まで照合した。 [3データの比較と機能差](MODEL_VALIDATION_TODO.md#軽量な分類での外部クロスチェックと機能差)
- **合成Voyagerの再現**。7日先の位置RMSEは、通常観測でDIY EKF、過去観測の混入条件で力学モデルのみが最小だった。EKFの観測更新と共分散、AutoGluonのモデル別記録、H2Oのイベントを保存した。H2Oでは学習48行に対して必要サンプル数に達しなかったGBM候補もログで確認した。 [Seeds・合成Voyagerの進捗付き比較](../experiments/automl_progress_comparison/README.md)
- **回帰テスト**。配布候補の作成時に全300件、進捗の追加後に302件、詳細図の追加後に開発環境（`.venv-dl`）で304件が通過した。最後の304件のJUnit結果は `runs/sl-report-modes-20261126/pytest.xml`。その後の比較スクリプトは個別に構文確認と実行を行った。

## 次回の進め方

1. リポジトリのルートで `git status --short --branch`、`git log -5 --oneline`、`git diff --stat`、`git ls-files --others --exclude-standard` を確認する。新規コード・テスト・実験記録を含め、配布候補以降の差分を把握する。
2. `.venv` が残っていれば、再接続時の疎通確認に下のIrisの手順を使う。環境がなければ11月24日の復元手順を参照する。標準データ一式や外部比較の再実行が必要な場合は、各実験レポートの再実行手順を使う。
3. 公開名、リポジトリ、ライセンスの判断を確認し、現時点のコードからwheelとソース配布物を作る。新規環境での導入に加え、`--progress both` と `--charts detail` を配布物から試せるようにする。その後のTestPyPIとColabの試用は配布手順に沿って進める。
4. 開発の後続候補は、欠損値補完・カテゴリ変換をfold内の学習側だけで決める前処理、学習済みモデルの再利用、探索予算・停止理由の記録。BPのC++・Qt Widgets化は別計画としてTo Doに保存済み。 [機能差と検討順](MODEL_VALIDATION_TODO.md#軽量な分類での外部クロスチェックと機能差) · [BPのQt計画](ROADMAP.md)

```powershell
$run = "runs/handoff-smoke-$(Get-Date -Format yyyyMMdd-HHmmss-fff)"
.\.venv\Scripts\python.exe -X utf8 -m diy_automl select --csv data/reference/iris.csv --target target --cpu-threads 1 --forest-jobs 1 --bootstrap-repeats 20 --progress both --output "$run/select"
.\.venv\Scripts\python.exe -X utf8 -m diy_automl report --run "$run/select" --charts detail --output "$run/report"
.\.venv\Scripts\python.exe -X utf8 scripts/validate_excel_report.py "$run/report"
```

引継ぎ作成時にもこの手順を実行し、進捗ログの保存、Excelの図4点、元のセル値の一致を確認した。確認結果は `runs/handoff-smoke-20261126-154634-228/` にある。
