# 検証計画

- 無効CSVを拒否し、原本を変更しない。
- SL/DLの学習だけでscalerをfitし、train/validation/testが重ならない。
- DL学習seedを変えても分割とscalerが不変で、重みが変わる。同seedは同CPU環境内で再現する。
- SL候補5件、UL候補54件が重複せず、seed42の反復割当が単回と一致する。
- 選定foldにtestが混入せず、25fold結果から1モデルだけtest評価する。同率許容値と候補順を確認する。
- bootstrapの再現性と条件付き完全予測のゼロ幅を確認する。
- UL反復の件数・全割当・失敗後のnot_runを確認する。
- 3データのCLI実行、保存結果検証、wheel独立実行を記録する。

これらは今回新規作成したテストであり、過去96件の復元ではない。テスト結果数の一致を目的としない。
