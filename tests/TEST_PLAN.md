# 検証計画

- 無効CSVを拒否し、原本を変更しない。
- SL/DLの学習だけでscalerをfitし、train/validation/testが重ならない。
- DL学習seedを変えても分割とscalerが不変で、重みが変わる。同seedは同CPU環境内で再現する。
- SL候補5件、UL候補54件が重複せず、seed42の反復割当が単回と一致する。
- 選定foldにtestが混入せず、25fold結果から1モデルだけtest評価する。同率許容値と候補順を確認する。
- bootstrapの再現性と条件付き完全予測のゼロ幅を確認する。
- UL反復の件数・全割当・失敗後のnot_runを確認する。
- 3データのCLI実行、保存結果検証、wheel独立実行を記録する。

これらは今回新規作成したテストであり、過去96件の復元ではない。テスト結果数の一致を目的としない。

## 0.4.0a2で追加

- repeat-dlは分割とscalerを一度だけ作り、同じ準備済みデータを全seedで共有する。
- seed42の単回と反復の予測・重み・履歴が一致する。元0.4.0a1.post1の保存済み3データの単回DL結果とも照合する。
- 不正seed/epoch/batch設定を出力作成前に拒否する。
- 最初・途中のseed失敗で、完了/失敗/未実行と部分履歴を保存する。実TensorFlowのepoch途中例外も検証する。
- manifestとExcel/NPZの対応、分割重複、seed順、指標と予測、集計値の不一致を検出する。
- TensorFlowが未導入でもコアのimportと保存結果検証器が利用できる。
- 3データ×10seed×100epochを開発環境と独立wheelで実行し、全配列と時間以外の表を照合する。
