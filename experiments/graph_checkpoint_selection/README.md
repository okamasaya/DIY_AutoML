# GCNの選定エポックと固定最終エポックを比較する

Coraの既知グラフで、同じ学習軌跡から二つのチェックポイントを比較した。1〜120エポックのうち選定macro F1が最も高い時点（同点なら最初）と、事前に固定した120エポック目を使う。各チェックポイントの予測を同じ保留ノードで採点する。 [データ・既存のGCNと分割仕様](../../docs/GRAPH_CLASSIFICATION.md)

分割seedと重みの初期化seedは別々に42〜46を指定し、全25組を実行した。各分割は学習140、選定514、保留2,054ノード。入力の特徴量と引用辺は既知で、ラベルは学習・選定・保留の用途ごとに使う。2層GCNの隠れ層は16、学習率は0.01、第1層のL2係数は0.0005。全組をCPU 1スレッドで120エポックまで学習した。

## 結果

| 指標 | 選定エポック | 固定120エポック | 差（選定 − 固定） |
| --- | ---: | ---: | ---: |
| 保留macro F1の平均 | 0.7733 | 0.7753 | −0.0020 |

選定区間では、選定エポックのmacro F1が平均で0.0037高かった。保留では選定エポックが7組で勝ち、3組が同点、15組で固定エポックが勝った。保留F1差の範囲は−0.0207〜+0.0090。選定エポックは71〜120で、中央値は111だった。

同じ分割でも初期化で差の符号が変わった。例えば分割seed 44の保留F1差は−0.0182〜+0.0090だった。チェックポイントを選ぶ区間での改善幅と、保留で再現した改善幅を併記する。25組は同じグラフを共有し、分割間でノードも重なるため、集計はこの条件での記述結果として扱う。

## 再実行と確認

リポジトリのルートで、準備済みの `cora.content` と `cora.cites` を指定する。取得方法は既存のGCNガイドにある。 [Cora入力の準備](../../docs/GRAPH_CLASSIFICATION.md#実行と保存結果)

```powershell
$cora = 'runs/gnn-cora-20261124'
& .\.venv\Scripts\python.exe -X utf8 -m experiments.graph_checkpoint_selection.run `
  --nodes "$cora/cora.content" --edges "$cora/cora.cites" `
  --split-seeds 42 43 44 45 46 --training-seeds 42 43 44 45 46 --epochs 120 `
  --output runs/graph-checkpoint-selection-new/cora
```

`report.xlsx` の `Checkpoint_Comparison` に分割・初期化の組、採用エポック、学習loss、選定・保留F1、学習時間を保存する。`arrays.npz` の `training_history` は組・エポックごとにエポック番号、学習loss、選定F1を保存し、同じ組順に予測配列を収録する。`manifest.json` に入力・コード・出力ハッシュと設定を記録する。

今回の出力は `runs/graph-checkpoint-selection-20261126/cora`。25組のF1を保存予測から再計算し、分割・ファイルハッシュを照合した。分割と初期化の両seedを42、43、44に揃えた3組は、以前の `gnn-compare` の選定エポック・予測と一致した。
